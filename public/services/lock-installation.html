MARYLAND LOCKSMITH REQUESTS

Replace or install a door lock.

Upgrade worn locks, add a deadbolt or replace hardware that no longer works correctly. A locksmith can review your existing door and hardware to determine whether a new cylinder, lockset or fresh installation is appropriate.

Request a locksmith →See all locksmith services

How to request this locksmith service

Identify the hardware

Mention the lock brand or type, such as deadbolt, knob, mortise lock or electronic keypad.

Describe the door

Say whether this is a replacement in an existing opening or a new lock installation.

Confirm parts and labor

Ask for an estimate that identifies the lock hardware, installation and any extra door preparation.

Common reasons customers request help

  • New deadbolt installation
  • Replace an old or damaged lock
  • Keypad or smart lock installation

Frequently asked questions

Can I provide my own lock?

You can ask the provider to install customer-supplied hardware. Compatibility and labor charges must be confirmed.

Will new locks work with my existing keys?

That depends on the lock manufacturer and keyway. Ask about compatible cylinders or rekeying.
