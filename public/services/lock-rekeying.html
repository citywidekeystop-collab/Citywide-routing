MARYLAND LOCKSMITH REQUESTS

Need your locks rekeyed?

Rekeying changes which key operates an existing compatible lock without necessarily replacing the entire lock hardware. It can be a practical option after moving, tenant turnover or a lost key.

Request a locksmith →See all locksmith services

How to request this locksmith service

Count the locks

Tell dispatch how many deadbolts, knobs or other cylinders need rekeying.

Mention key preferences

Tell the provider if you want compatible locks keyed alike to one key.

Compare repair options

If hardware is worn or damaged, the locksmith may recommend replacement rather than rekeying.

Common reasons customers request help

  • Rekey locks after moving
  • Change keys after losing a key
  • Rekey rental property or business locks

Frequently asked questions

Is rekeying the same as replacing a lock?

No. Rekeying changes internal cylinder pinning where compatible; replacing changes the hardware itself.

Can all locks use one key?

Some compatible locks can be keyed alike. A locksmith needs to review brands, keyways and cylinder types.
